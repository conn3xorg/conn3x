# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/conn3xorg/conn3x/discussions)
- **Bugs:** [open an issue](https://github.com/conn3xorg/conn3x/issues/new/choose)
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them in public.

breaking change.
